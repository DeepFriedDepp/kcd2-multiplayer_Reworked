The four NPCs with the most total drop and the highest fight-correlation
(`ttkc_man_7`, `ttkc_drozd`, `ttkc_man_10`, `ttkc_man_21`) are combat NPCs and
mostly dip *during* a fight — this matches WO-129 §7's suspicion ("at least
once when the host started a fight") much more closely than anything
reproduced there. The two `dummyWanderer_*` entries never coincide with a
fight and are more likely ordinary terrain-following (a sloped street) —
horizontal displacement wasn't tracked for early rows so this isn't fully
separable from a real sink; flagged as (inconclusive).

**Not answerable this session**: whether the *joiner's copy* of these same
