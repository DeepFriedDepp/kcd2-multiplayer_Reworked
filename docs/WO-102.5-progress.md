## End gate details (0.25.0, original)

* **Fresh-clone build.** `git clone` of `origin/main` at `d12d264` into a
  scratch directory (never the working tree). Native configure/build:
  `cmake -S native -B native/build -G Ninja -DKCDMP_BUILD_EXPERIMENTS=OFF`
  then `cmake --build native/build` (both targets: `KCDMP.dll`,
  `KCDMP_LauncherInjector.exe`). Then `tools/Build-Installer.ps1`
  end-to-end: pak rebuild, all three gates, publish, install manifest,
  Inno Setup compile.
* **A real privacy regression, found by actually re-running the sweep, not
  by assuming WO-98's fix still held.** `KCDMP.dll` and
  `KCDMP_LauncherInjector.exe` both embedded the build machine's absolute
  local path (MSVC's default PE debug-directory behaviour) — WO-98 §0 had
  recorded the native DLL carrying none, so this is either a genuine
  regression or a gap in how thoroughly that session checked natives.
  Fixed with `/PDBALTPATH:%_PDB%` in `native/CMakeLists.txt` (applies to
  every linked target); verified by rebuilding and byte-scanning both
  shipped binaries directly (UTF-8 and UTF-16LE) — zero hits, before
  re-cloning and rebuilding the whole release from scratch with the fix in.
* **Privacy sweep methodology**: byte-scanned every file under the fresh
  clone's `release/` output (1,024 files) for three needles — the build
  account's name, the DDNS provider domain from this session's own
  environment, and the associated mailbox name — each checked as both raw
  ASCII/UTF-8 and UTF-16LE. One hit: `KCDMP_launcher.dll` contains the
  literal string `"...such as myserver.duckdns.org, or an IP address"` —
  a WO-55 input-validation error message using a GENERIC example hostname,
  not a real one. Confirmed benign by reading the surrounding string in
  context, not assumed.
* **Pak verification**: read `kdcmp/Data/kdcmp.pak` from the built clone
  directly and confirmed six of this session's own log-line/function-name
  markers are present as literal bytes (`WO1025-COLOCATE`,
  `KCD2MP_SetAuthorityRadius`, `KCD2MP_ApplyNativeScan`, `mp_npc_cull_on`,
  `WO102-AUTHORITY reconcile`, `NPCSCAN dir=consume`) — the shipped pak is
  not the repo's committed one (WO-94's own caution), so this checks the
  ACTUAL bytes ISCC is about to embed, not the source tree.
* **Not done**: the installer itself was not run (AppData sandbox
  redirection — the maintainer runs Setup + `Verify-Install.ps1`, per
  standing session practice). The Setup exe and release notes are handed
  off, not self-verified end to end.

are false now; left in place they are exactly what a future session would
read as current status, so this replaces rather than appends to them.

  `path=native`/`LOCALSTATE` lines in any bundle to date. Shipped ON anyway

  is (GameBridge disarms it after 20 consecutive pipe refusals or 20
  samples >3 m from the log-line oracle), and both machines are expected
  on a matched 0.25.1+ build, so the older-DLL stall risk does not apply.
  "Unmeasured" stopped being treated as a reason to keep it off; it is not
  the same claim as "verified."

  unverified live at MATCHED radii — the one live run predates the fix and
  compared 30 m against 45 m, so it could not have caught a native miss in
  that band. Re-running `mp_npc_scan_compare` with both sides at the same
  radius is a thirty-second live check, not yet done.
* The 150 m authority radius's real FPS cost, measured with the game
  window actually in focus — the only attempt (findings §6.3) was
  retracted as a window-focus throttling artefact, not a radius
  measurement. Zero (observed) cost evidence in either direction now.
* No per-path cadence comparison for the scan (findings §2.3 item 5) — a
  real gap against the WO's own "measure both paths" ask, unchanged since
  first named.
* Co-location's 60/90 m hysteresis band and 10 s dwell (Phase 4) are still
  a first guess — no two-machine session has ever exercised the actual
  together/apart transition.
* Village-location radius numbers, and native-scan-off numbers at the same
  radii, for a real on/off cost comparison — only one location (a town,
